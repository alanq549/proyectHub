Genera siempre los mensajes de commit en español.

Reglas:
- Usa el formato Conventional Commits.
- El tipo (`feat`, `fix`, `refactor`, `docs`, `chore`, etc.) se mantiene en inglés.
- La descripción debe estar completamente en español.
- Escribe una sola línea.
- Máximo 70 caracteres cuando sea posible.
- Resume únicamente el cambio principal.
- No enumeres archivos ni detalles internos.
- No agregues explicación, cuerpo, notas ni viñetas.
- No uses inglés en la descripción, salvo nombres propios, APIs o tecnologías.
